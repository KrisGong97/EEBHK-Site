登录

用 GitHub 个人访问令牌登录后，即可在网页里新建、修改、保存新闻和联系方式。保存会写入仓库并自动部署。

1. 打开 创建 Fine-grained Token
2. Resource owner 选你的账号，Repository 只勾选 EEBHK-Site
3. Permissions → Contents 选 Read and write，生成后粘贴到下方
令牌只存在本机浏览器，关闭标签页即清除。请不要发给他人。
